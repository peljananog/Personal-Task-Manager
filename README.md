## Features Implemented

- **Add Task:** Allows users to create new tasks with title, description, due date, and initial status.
- **View Tasks:** Displays a clean list/table of all tasks with details and a dedicated modal popup view for complete task information.
- **Edit Task:** Allows editing of existing task details (title, description, due date, status) via a dynamic modal view.
- **Delete Task:** Enables removal of unwanted tasks with confirmation prompt.
- **Update Status:** Easy tracking and update of task status (Pending, In Progress, Completed).

- **Framework:** Laravel
- **Frontend:** Blade Templates, Bootstrap 5, FontAwesome
- **Database:** SQLite
